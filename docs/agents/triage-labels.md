# Triage Labels

| Canonical role    | Tracker label     | Meaning                                  |
| ----------------- | ----------------- | ---------------------------------------- |
| `needs-triage`    | `needs-triage`    | Maintainer needs to evaluate the issue   |
| `needs-info`      | `needs-info`      | Waiting for more information             |
| `ready-for-agent` | `ready-for-agent` | Ready for autonomous implementation      |
| `ready-for-human` | `ready-for-human` | Requires human implementation            |
| `wontfix`         | `wontfix`         | Will not be actioned                     |

## Additional workflow labels

| Workflow  | Tracker label | Meaning                                      |
| --------- | ------------- | -------------------------------------------- |
| `to-spec` | `spec`        | The issue contains a completed specification |

When a skill mentions a canonical role or workflow, use the corresponding tracker label.
