# Domain Docs

This is a single-context repository.

## Before exploring

Read:

- `CONTEXT.md`
- Relevant decisions under `docs/adr/`

If either location does not exist, proceed silently.

## Use the glossary vocabulary

Use terms defined in `CONTEXT.md` in issues, plans, tests, and implementation. Avoid synonyms the glossary explicitly rejects.

If a required concept is absent, reconsider the terminology or note the gap for domain modeling.

## Flag ADR conflicts

Explicitly identify proposals that contradict an existing ADR rather than silently overriding the decision.
